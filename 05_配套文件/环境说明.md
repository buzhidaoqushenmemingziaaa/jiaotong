## 1 一句话总结
**Python 3.13 + PuLP 3.3.2 + tkinter**，除此之外只剩数据可视化三件套。**没有任何需要联网的运行时依赖**，离线可跑。

## 3 ★ 最大的坑：PuLP 版本必须钉死在 3.3.2
我实测过：直接 pip install pulp 现在会装到 **4.0.0**，而那个 wheel 里**不含 CBC 可执行文件**（解包后 89 个文件，cbc 出现 0 次）。装上去之后 PULP_CBC_CMD 会在求解时报文件找不到。
**正确做法：**

```bash
pip install "pulp==3.3.2" numpy pandas matplotlib
```

装完立刻自检：

```bash
python -c "import pulp,os;p=pulp.PULP_CBC_CMD().path;print(os.path.normpath(p),os.path.exists(os.path.normpath(p)))"
# 期望输出：D:\Lib\site-packages\pulp\solverdir\cbc\win\i64\cbc.exe True
```

只要最后是 True 就没问题；是 False 说明装成了 4.0.0，卸掉重装。

### 离线安装（没有网络的机器）
在能联网的机器上先下好 wheel：

```bash
pip download "pulp==3.3.2" numpy pandas matplotlib -d wheels --only-binary=:all:
```

把整个 wheels/ 目录拷过去，然后：

```bash
pip install --no-index --find-links=wheels "pulp==3.3.2" numpy pandas matplotlib
```

**注意 pip download 也要写 pulp==3.3.2**，否则一样会下到 4.0.0。

### 两条铁律
1. **engine/ 里不许出现 import tkinter**，也不许 print 到 stdout 当输出通道——结果一律通过返回值传出。
1. **ui/ 里不许直接建模型**。界面只做三件事：读配置 → 调 run_case(config) → 把返回的 dict 画出来。
违反任一条，W4 之后的界面联调必然返工。

## 6 编码规范
- **源码与注释一律 UTF-8**，中文注释正常写。Windows 下读写文件务必显式写 encoding="utf-8"——本机默认编码是 GBK，不写会直接崩。
- 控制台输出中文乱码时，脚本开头加：

```python
  import sys
  sys.stdout.reconfigure(encoding="utf-8", errors="replace")
```

或者在命令行用 python -X utf8 your_script.py。
- 公式里的角标在**代码注释**里用 a[t][r]、b[t][d] 这种写法就行，不必强行还原成真上下标——真上下标只在 Word 交付文档里要求。
- 命名跟《模型规范》一致：x[t][d] 唤醒数、u[t][d] 上线数、b[t][d] 待班数、a[t][r] 交路车底数、lam[t][r][k] 档位选择。**不要自己另起一套符号**，否则论文对不上代码。
- 每个模块顶部写清楚它对应《模型规范》的哪一节 / 哪几条约束。

## 7 已知的坑（踩过的）

| **现象** | **原因** | **处理** |
| --- | --- | --- |
| PulpSolverError: Pulp: cannot execute cbc | 装成了 PuLP 4.0.0 | pip install "pulp==3.3.2" |
| UnicodeDecodeError: 'gbk' codec can't decode | 读文件没写 encoding="utf-8" | 所有 open() 显式指定 |
| 控制台 UnicodeEncodeError | GBK 控制台打不出 ∀ ≤ ⌈ 等符号 | python -X utf8 或 sys.stdout.reconfigure |
| matplotlib 中文变方框 | 没设中文字体 | matplotlib.rcParams["font.sans-serif"] = ["Microsoft YaHei"] |
| 求解很慢 / 无解 | 先看配置校验有没有过，再看时间窗与车底档位 | 先跑 check_config.py |
