# Mock 后端使用说明

零依赖，只用 Python 标准库。

## 启动

```bash
python mock_server.py                # http://127.0.0.1:8800
python mock_server.py --port 9000    # 换端口
python mock_server.py --delay 6      # 模拟求解 6 秒（默认 4 秒）
```

## 自检

```bash
curl http://127.0.0.1:8800/api/health
```

返回：
```json
{"ok": true, "mock": true, "cases": [...]}
```

## 它是什么 / 不是什么

- ✅ **是**：契约形状的真实接口，返回 A 的原型跑出来的**真实结果**
- ❌ **不是**：编造的假数据。数值量级可直接用于做图与联调
- ⚠️ **是 mock**：/api/compare 与 /api/sweep 的结果由真实结果**派生**，
  形状正确、量级合理，但不是真算出来的

## 为什么默认有 4 秒延迟

**故意让你按"求解是慢操作"来设计前端。**
B 的引擎无论 3 秒还是 60 秒，你的异步设计都能适配；
反过来，如果你按"秒回"设计，B 一慢就要返工。

## 切换成真后端

你的 aseURL 从 `http://127.0.0.1:8800` 换成 B 的地址即可，
**前端代码不应有任何改动**。这正是验收标准之一。
